# POLISY lab site

Built 2026-09-28 09:20 by polisy_lab 0.1.0 (2026-09-25).

- `index.html`: the lab (Plotly loads from jsDelivr).
- `polisy_lab_offline.html`: the same page with Plotly inlined; opens without internet.

GitHub Pages: put this folder in a repository (for example as `docs/`), then Settings -> Pages -> Deploy from a branch -> choose the branch and the folder.
